# Security policy

## Reporting a vulnerability

Please report vulnerabilities privately with GitHub's **"Report a vulnerability"** button on the repository's Security tab. Do not open a public issue.

We especially want to hear about:

- Repository content (diffs, rules files, `AGENTS.md`) that makes the reviewer do something other than review — prompt injection that leads to reading files outside the repo, leaking secrets, or running commands.
- Secrets or API keys being sent to a provider, written to settings, or logged.

We'll acknowledge reports within a few days and keep you updated on the fix.
