New AI Review sidebar: click the icon in the Activity Bar to open the **Review** panel, choose what to review (unstaged, staged, branch with a base branch picker, current file or selection), the repository, model, review mode and context, then press **Run Review** (or **Cancel Review**). Findings moved from the Source Control sidebar into the same sidebar. New commands: **AI Review: Run Review**, **Cancel Review** and **Open Review Panel**.
